• 明白。按你这个框架，我会把边界划清楚：

  dataloader:
    只负责按 timestamp 对齐 ft / img / lowdim
    不做 encoder
    不做 cross attention

  model:
    img encoder
    ft encoder
    optional lowdim encoder
    cross attention fusion
    输出 DP 的 obs condition

  DP:
    仍然训练 action trajectory

  这样设计更合理。尤其是你要做 cross attention，就不应该把 FT flatten 成普通 lowdim，而应该在 dataloader 保留 FT 的时间窗口结构。

  推荐 dataloader 输出：

  batch["obs"]["ee_cam_color"]            # [B, To, C, H, W]
  batch["obs"]["third_person_cam_color"]  # [B, To, C, H, W]
  batch["obs"]["state_ee"]                # [B, To, D_state]
  batch["obs"]["ft_data"]                 # [B, To, K, D_ft]
  batch["obs"]["ft_mask"]                 # [B, To, K]  可选但建议
  batch["action"]                         # [B, horizon, D_action]

  其中：

  To = n_obs_steps
  K = 每个 image timestamp 对齐出来的 FT 帧数
  D_ft = 6 或你的 FT 维度

  FT 对齐语义可以定义成：

  对每个 obs image timestamp t_img:
    ft_data[t_img] = FT in (t_img - ft_window_sec, t_img]

  比如：

  image: 30Hz
  FT: 200Hz
  ft_window_sec = 0.05
  K = 10

  那么每张图像都配最近 50ms 的 10 帧 FT。

  进入 model 后：

  img encoder:
    [B, To, C, H, W] -> [B, To, N_img_tokens, D]

  ft encoder:
    [B, To, K, D_ft] -> [B, To, K, D]

  cross attention:
    image tokens query FT tokens
    或者 FT tokens query image tokens
    或者 concat tokens 后 self-attention

  fusion output:
    [B, To, D_fused]

  DP condition:
    [B, To * D_fused]

  对你现在的 DiffusionUnetImagePolicy 来说，它当前会把 obs 的时间维压到 batch 维：

  [B, To, ...] -> [B * To, ...]

  所以一个兼容现有 policy 的新 obs encoder 可以设计成：

  img: [B*To, C, H, W]
  ft:  [B*To, K, D_ft]
  state: [B*To, D_state]

  -> cross attention fusion
  -> feature: [B*To, D_fused]

  然后 policy 里再 reshape 成：

  [B, To * D_fused]

  这和当前 DP global condition 逻辑是兼容的。

  关键原则：

  1. 主时间轴仍然是 img/lowdim/action 的 LeRobotV3
     FT 数据集只被查询，不决定 sample index。
  2. FT 必须按 episode 内 timestamp 对齐
     不跨 episode search。
  3. timestamp 保持 float64 秒
     你的 61828.113963315 不能转 int。
  4. dataloader 输出原始 FT window
     不在 dataloader 里 encode，不 flatten，保留 [To, K, D_ft] 给 model cross attention。
  5. 训练和部署保持一致
     如果真实机器人上只能拿到当前图像之前的 FT，就训练也只用 <= t_img 的 FT。

  所以你的整体架构我建议定成：

  HirolLeRobotV3Dataset:
    main_lerobot: img + lowdim + action
    ft_lerobot: ft + ft_timestamp

    __getitem__:
      sample obs_indices from main_lerobot
      load img/lowdim
      for each obs timestamp:
        search FT window in same episode
      return raw aligned obs

  New multimodal obs encoder:
    image encoder
    ft temporal encoder
    state encoder
    cross attention fusion
    return fused condition feature

  DP policy:
    unchanged or minimally changed

  这个方向比把 FT 塞成普通 lowdim 更适合你说的 cross attention 框架。
